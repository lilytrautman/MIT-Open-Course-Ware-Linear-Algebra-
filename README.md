## About the Course

This course covers matrix theory and linear algebra, emphasizing topics useful in other disciplines such as physics, economics, engineering, statistics, and computer science. Linear algebra is a cornerstone of machine learning, data science, computer graphics, and scientific computing.

**Instructor:** Prof. Gilbert Strang  
**Institution:** Massachusetts Institute of Technology  
**Level:** Undergraduate  


## Course Structure

### Unit I: Ax = b and the Four Subspaces

The foundational unit covering systems of linear equations and the geometry of linear algebra.

| Topic | Description |
|-------|-------------|
| The Geometry of Linear Equations | Row and column pictures of linear systems |
| Elimination with Matrices | Gaussian elimination, back substitution |
| Multiplication and Inverse Matrices | Matrix operations, computing inverses |
| Factorization into A = LU | LU decomposition |
| Transposes, Permutations, Vector Spaces | Fundamental concepts |
| Column Space and Nullspace | Understanding the four fundamental subspaces |
| Solving Ax = 0: Pivot Variables, Special Solutions | Homogeneous systems |
| Solving Ax = b: Row Reduced Form R | Complete solution |
| Independence, Basis and Dimension | Core definitions |
| The Four Fundamental Subspaces | Column space, nullspace, row space, left nullspace |
| Matrix Spaces; Rank 1; Small World Graphs | Applications |
| Graphs, Networks, Incidence Matrices | Graph theory connections |

### Unit II: Least Squares, Determinants and Eigenvalues

Orthogonality, projections, and the spectral theory of matrices.

| Topic | Description |
|-------|-------------|
| Orthogonal Vectors and Subspaces | Perpendicularity in higher dimensions |
| Projections onto Subspaces | Projection matrices |
| Projection Matrices and Least Squares | Data fitting, regression |
| Orthogonal Matrices and Gram-Schmidt | QR factorization |
| Properties of Determinants | The 10 key properties |
| Determinant Formulas and Cofactors | Computing determinants |
| Cramer's Rule, Inverse Matrix and Volume | Geometric interpretation |
| Eigenvalues and Eigenvectors | The eigenvalue problem |
| Diagonalization and Powers of A | Matrix decomposition |
| Differential Equations and exp(At) | Systems of ODEs |
| Markov Matrices; Fourier Series | Stochastic matrices, orthogonal functions |

### Unit III: Positive Definite Matrices and Applications

Advanced topics and real-world applications.

| Topic | Description |
|-------|-------------|
| Symmetric Matrices and Positive Definiteness | Spectral theorem |
| Complex Matrices; Fast Fourier Transform (FFT) | Hermitian matrices, FFT |
| Positive Definite Matrices and Minima | Optimization |
| Similar Matrices and Jordan Form | Matrix similarity |
| Singular Value Decomposition | The SVD |
| Linear Transformations and their Matrices | Abstract view |
| Change of Basis; Image Compression | Applications |
| Left and Right Inverses; Pseudoinverse | Moore-Penrose inverse |
